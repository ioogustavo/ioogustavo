# 🏗️ Enterprise Experience

## Banking Systems @ Galicia

Worked on nationwide banking platforms handling large-scale commerce and geolocation systems.

### Main Contributions

- Maintained and evolved distributed backend ecosystems composed of multiple repositories and services
- Participated in scalable backend architectures designed to avoid global service failures
- Worked on modular enterprise systems with service separation and decoupling strategies
- Designed and optimized APIs for large-scale business flows
- Worked with enterprise-level geospatial systems and coordinate-based filtering

### Geospatial Optimization

One of the most challenging engineering problems I worked on involved nationwide commerce geolocation queries.

### Problem
- Queries retrieving commerces across the entire country were taking around 6 seconds
- Massive unnecessary data transfer
- Geographic filtering inefficiencies

### Solution
- Implemented coordinate-based filtering strategies using PostgreSQL/PostGIS
- Designed bounding-area query approaches around geographic points
- Reduced query overhead by filtering only nearby commerces
- Improved scalability and reduced traffic significantly

### Technologies Involved
- PostgreSQL
- PostGIS
- SQL Optimization
- Geospatial Filtering
- Backend APIs
